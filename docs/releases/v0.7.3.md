# HydraCup v0.7.3

## 更新結果保留到重開機之後

每次 OTA 都以重新開機收尾，因此更新結果只在畫面上存在約 2.5 秒——而那正是使用者不會盯著看
的時刻。v0.7.1 的 webfs 失敗就是這樣被錯過的：訊息一閃即逝，重開後頁面重新載入，什麼都不剩，
只能靠推理還原發生了什麼。

現在最後一次更新的結果會寫進 NVS，開機後由 `GET /api/ota/status` 以 `last_outcome` 回傳，
設定頁「08 韌體更新」會顯示「上次更新結果：⋯」。不論成功或失敗、不論當下有沒有人在看，
重開後都查得到。

## 這一版也是轉址修正的第一次真正驗證

v0.7.2 修好了 webfs 下載不跟隨轉址的問題，但那次更新是由**尚未修正的 v0.7.1 韌體**執行的，
所以修正沒有機會生效——OTA 的修正永遠只能由下一次更新來驗證，因為執行下載的是舊韌體。

本版由已含修正的 v0.7.2 執行下載，因此是第一次真的走到修正後的路徑。若 webfs 這次成功，
設定頁會出現「10 清除飲水紀錄」卡片（它從未透過 OTA 送達過），且狀態會顯示「網頁資源已更新」。

## 驗證

- `pio run -e esp32dev`
- `pio run -e esp32dev --target buildfs`
- `pio test -e native`
